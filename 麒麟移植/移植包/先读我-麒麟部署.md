# 银河麒麟 · 先做这一步

## 一、把整个文件夹拷到麒麟上

拷到任意位置，例如  家目录/抽签点名

## 二、打开终端，执行环境探测

在该文件夹里右键 -> 「在终端中打开」，然后执行：

    bash 检查环境.sh

把屏幕上的**全部输出**复制下来发给我。

## 三、为什么必须先探测

你的麒麟机器**没有 root 权限**，意味着不能安装任何系统包。

如果系统自带 tkinter，"启动.sh" 双击就能用；
如果没有，我就得换成不依赖任何额外组件的方案（纯网页版，用浏览器打开）。

所以第 3 项「图形界面能力」的结果决定用哪种方案，先别急着双击启动。

## 四、如果探测结果显示 tkinter 可用

直接双击 "启动.sh"（或终端执行 ./启动.sh）即可开始抽签。

首次双击如果提示权限不足：
    右键 启动.sh -> 属性 -> 权限 -> 勾选「允许作为程序执行文件」
或者终端执行：
    chmod +x 启动.sh
