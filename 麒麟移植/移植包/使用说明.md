# 抽签点名 · 使用说明

## 直接开始用（Windows）

1. 双击 **`抽签点名.exe`**（窗口打开，不会占满全屏）
2. 点 **「开始抽签」**（或按空格、或点画面）→ 名字开始滚动
3. 再点一次 → **减速**，最后停在中奖的人身上
4. 点「再抽一次」继续

| 操作 | 效果 |
|---|---|
| 空格 / 回车 | 开始抽签 / 停止 |
| 点击滚轮画面 | 同上 |
| 双击滚轮画面 | 最大化 / 还原窗口 |
| F11 | 最大化 / 还原窗口 |
| Esc | 退出 |

- **字号固定不变**：所有名字都是同一个字号，不会因为名字长短而变大变小
- **窗口可以随意拖动、缩放**；缩小时滚轮的行数会自动减少，字号始终不变
- 抽中的人行有金色高亮带和两侧三角指示

---

## ⚠️ 最重要的一条：`抽签点名.exe` 和 `_internal` 必须放在一起

`抽签点名.exe` **不能单独拷走**。它旁边的 `_internal` 文件夹装的是运行所需的组件，
两个必须在一起，缺了就打不开。

- 正确的做法：**整个文件夹一起拷**（拷到 U 盘、拷到教室电脑，都一样）
- 已经打包好的压缩包：`抽签点名-Windows版.zip`，直接解压到任意位置即可用

**不需要安装任何东西**，也不用装 Python——教室电脑、别人电脑都能直接双击运行。

---

## 换名单

用记事本打开同目录的 **`num.txt`**，每行一个名字，保存，重新打开程序即可。

- 目前里面是 **43 个名字**
- 编码用 ANSI 或 UTF-8 都行，程序会自动识别
- 想准备多份名单（比如 1 班、2 班）：
  把名单存成别的 `.txt`，然后**直接把这个 txt 文件拖到 `抽签点名.exe` 上**，就用那份名单

## 你原来遇到的报错，到底是怎么回事

截图里的报错是：

```
ERROR: /home/seewo/下载/2班新/award.exe : Can not open
```

这是 **两件事叠在一起**，跟"软件坏了"没关系：

**第一，你拿到的那份文件包是残缺的。**
原版「倾诚软件 抽奖抽签程序 1.1」是 2006 年的 Windows VB6 程序。
而你那个文件夹里**只有设置程序 `Settings.exe`，主程序 `award.exe` 根本不在里面**
（`COMDLG32.OCX`、`award.ini`、`back*.JPG`、`num.txt`、`result.txt` 都在，唯独缺主程序）。
当年分享这类软件时常有人只传了设置程序，主程序丢了。

**第二，那台机器是 Linux（Mint），不是 Windows。**
报错的「归档管理器」是 Linux 的解压工具。`.exe` 是 Windows 可执行文件，
Linux 根本无法执行，所以它报 `Can not open`——**这不是程序运行中出错，是它压根打不开这个文件**。

**结论：不用再折腾那个 `.exe` 了。** 名单（`num.txt`）是完好的，
本程序直接读你的名单，在 Windows 上双击就能用。

## 文件夹里每个文件是什么

主目录（要用的都在这里）：

| 文件 | 说明 |
|---|---|
| **`抽签点名.exe`** | **主程序，双击运行** |
| **`_internal`** | 运行组件，**必须和 exe 放在一起** |
| `num.txt` | 名单（43 人），改这个就是换名单 |
| `result.txt` | 原版 2019–2026 年的历史记录，**保留不动** |
| `result_linux.txt` | 新版程序的抽签记录，第一次抽签后自动生成 |
| `抽签点名.py` | 源码，留着备查（改字号 / 改速度用，日常不需要） |
| `使用说明.md` | 本文件 |

子文件夹 `原版文件\`（新版程序一个都用不到，只是没删）：

| 文件 | 原来是什么 |
|---|---|
| `Settings.exe` | 原版的设置程序 |
| `COMDLG32.OCX` | 原版 VB6 运行库 |
| `award.ini` | 原版配置 |
| `back0~3.JPG` | 原版背景图 |
| `Readme.txt` 等 4 份 | 原版说明文件与许可协议 |

详见 `原版文件\说明-这里是什么.md`。**确认不需要的话，这个子文件夹可以整个删掉。**

## 补充说明

- **抽签是每次独立随机的，同一个人可能被连续抽到两次。**
  这是原版的语义（`award.ini` 里 `Repeat=False`），也是抽签的正常含义。
- 想改字号：打开 `抽签点名.py`，把 `NAME_SIZE = 46` 改成你要的数值。
- 想改停止快慢：打开 `抽签点名.py`，改这两个值（越小停得越快）：
  - `ROLL_DURATION = 850` —— 减速停止耗时（毫秒），当前约 0.85 秒
  - `SLOW_TURNS = 2` —— 停止前多转几圈
  （改完需要重新打包才能生成新的 exe，直接跑 `.py` 也能看效果。）
- 如果 Windows 提示"已保护你的电脑"（蓝色窗口）：
  点「更多信息」→「仍要运行」即可。这是对未签名程序的常规提示。
- 如果双击后没反应，先确认 `_internal` 文件夹还在 exe 旁边。
