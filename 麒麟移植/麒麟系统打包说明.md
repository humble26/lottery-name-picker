# 抽签点名 · 麒麟系统打包说明

## 一、适用版本

本说明适用于 **银河麒麟 / 中标麒麟**（Kylin）桌面系统，含 x86_64（Intel/AMD/**海光 Hygon**）和 ARM64（飞腾、鲲鹏）架构。
源码已做跨平台适配，Windows 和麒麟系统均使用同一份源码。

> 本机环境已验证：**银河麒麟 x86_64 + 海光 C86（Hygon C86-3G）**，属 x86_64 架构，直接按下文执行即可。

> 重要：**打包必须在目标架构的麒麟系统上执行**。x86_64 打包出的程序只能在 x86_64（Intel/AMD/海光）上运行，飞腾（ARM64）必须用 ARM64 机器打包，两者不能互换。

---

## 二、准备工作（在麒麟系统上执行）

打开终端，依次执行以下命令安装环境：

```bash
# 1. 安装 Python3 与 tkinter 图形库（麒麟默认不带 tkinter，必须安装）
sudo apt update
sudo apt install -y python3 python3-tk python3-pip

# 2. 安装打包工具和图像库
sudo pip3 install pillow pyinstaller

# 3. 若中文显示为方块，安装中文字体
sudo apt install -y fonts-noto-cjk
# （或）sudo apt install -y fonts-wqy-zenhei
```

验证环境：

```bash
python3 -c "import tkinter, PIL; print('OK')"
```

输出 `OK` 即环境就绪。

## 三、拷贝源码

将本目录下的 `源码/award_app.py` 拷贝到麒麟系统任意目录（如 `~/抽签点名/`），并把以下数据文件一并拷贝过去：

- `num.txt`（名单，可先放一份）
- `award.ini`（配置文件，可让程序首次运行时自动生成）
- `back0.JPG`、`back1.JPG` 等背景图（可选）

建议目录结构：

```
抽签点名/
├── award_app.py   ← 源码
├── num.txt        ← 名单
├── award.ini      ← 配置
└── back0.JPG      ← 背景（可选）
```

---

## 四、打包成免安装程序

在源码所在目录执行：

```bash
cd ~/抽签点名
pyinstaller --onefile --name 抽签点名 award_app.py
```

打包完成后，可执行文件位于 `dist/抽签点名`。

> 说明：
> - `--onefile`：打成单个可执行文件，免安装、可拷贝
> - Linux 下无需 `--windowed` 参数（GUI 程序不会弹出控制台窗口）
> - 若需要图标，可在打包命令后加 `--icon=图标.png`（Linux 使用 PNG 格式）

---

## 五、运行

```bash
# 给执行权限（首次）
chmod +x dist/抽签点名

# 运行
./dist/抽签点名
```

也可以双击文件管理器中的程序图标运行。

程序运行时会在**可执行文件所在目录**查找 `num.txt`、`award.ini`，因此请将数据文件与程序放在同一目录（或程序旁），与 Windows 版使用习惯一致。

## 七、常见问题

**1. 中文显示为方块？**
系统中文字体未安装。执行 `sudo apt install -y fonts-noto-cjk` 后重启程序。

**2. 双击程序无反应？**
先确认有执行权限（`chmod +x`）；再在终端运行 `./抽签点名` 查看报错信息，通常是缺少依赖（对照第二节重新安装）。

**3. 在飞腾/鲲鹏机器上打包的程序，能否拷到 x86 机器运行？**
不能。架构不兼容，必须在对应架构的麒麟机器上分别打包。

**4. 名单文件编码问题？**
程序自动兼容 UTF-8 和 GBK 编码的 `num.txt`，Windows 上现有的名单文件可直接使用，无需转换。

**5. 能否把现有 Windows 的 result.txt 带过去？**
可以，格式兼容，程序会继续追加写入。
