# 抽签点名 · Lottery Roll-Call

课堂上抽人回答问题的老虎机式小工具：点一下开始滚名字，再点一下减速，最后停在中奖的人身上。
Windows 与银河麒麟（信创环境）双平台可用，**零第三方依赖**，只要机器上有 Python 3 + tkinter 就能跑。

> 本仓库是**纯 Python 重写版**。代码、界面、打包脚本均为本人所写，与上游 VB6 程序无代码继承关系 ——
> 细节见下方[与上游的关系](#与上游的关系)。

---

## 三种实现

| 位置 | 行数 | 说明 |
|---|---|---|
| `Windows版/抽签点名.py` | 500 | 老虎机滚轮窗口版。字号固定不变（不随名字长短缩放），窗口可自由拖动缩放，缩小时自动减少行数 |
| `增强版-traework-20260917/源码/award_app.py` | 969 | 功能增强版。读 `num.txt` 名单 + `award.ini` 配置，支持**防重复**、速度调节、背景自由更换、结果自动保存，并**兼容原版 `result.txt` 格式** |
| `麒麟移植/移植包/抽签点名.py` | 500 | 银河麒麟 / 中标麒麟移植版。与 Windows 版同一份源码，跨平台适配 |

`麒麟移植/验证脚本/test_zoom.py` 是针对窗口缩放逻辑的回归测试（108 行），用真实 App 实例跑平台分支。

## 特性

- **字号恒定**：所有名字同一字号，不会因为名字长短而忽大忽小
- **窗口随意缩放**：滚轮行数随窗口高度自动增减，字号始终不变
- **中奖高亮**：抽中的人行有金色高亮带与两侧三角指示
- **换名单简单**：编辑 `num.txt`（每行一个名字）即可；也可把任意 `.txt` 拖到程序上临时换名单
- **抽签记录**：每抽中一人追加写入 `result_linux.txt`，不改动历史记录文件
- **键盘操作**：空格 / 回车开始与停止，双击或 F11 最大化，Esc 退出

## 快速开始

```bash
cd Windows版
cp num.example.txt num.txt        # 换成你自己的名单
python 抽签点名.py
```

没有 Python 的话，Windows 上可以自行打包成免安装 exe：

```powershell
cd Windows版
pip install pyinstaller
pyinstaller --noconfirm --windowed --onefile --name 抽签点名 抽签点名.py
# 产物在 dist\ 下
```

> **onedir 打包时 `抽签点名.exe` 与 `_internal\` 必须放在一起**，缺一个都打不开。
> 拷到教室电脑时请整个文件夹一起拷。

### 麒麟（Kylin）部署

```bash
sudo apt install -y python3 python3-tk python3-pip   # 麒麟默认不带 tkinter
cd 麒麟移植/移植包
bash 检查环境.sh          # 先探测环境（无 root 权限的机器尤其要先跑这一步）
python3 抽签点名.py
```

完整的打包与架构注意事项见 [`麒麟移植/麒麟系统打包说明.md`](麒麟移植/麒麟系统打包说明.md)，
其中说明了 **x86_64（Intel/AMD/海光）与 ARM64（飞腾/鲲鹏）必须各自在目标架构上打包，不能互换**。

## 与上游的关系

本项目的**起点**是一份 2006–2007 年的 Windows VB6 免费软件「倾诚软件 抽奖抽签程序 1.1」，
当时手上有它的配置与背景素材（`Settings.exe`、`COMDLG32.OCX`、`award.ini`、背景图等）。
但那份分享里**主程序 `award.exe` 已经丢失**，只剩设置程序，因此无法直接使用。

于是本仓库的做法是：**用 Python 从零重写整个程序**，只沿用了「抽签点名」这个用途、
以及原版 `result.txt` 的历史数据格式（增强版刻意保持兼容，以便读取 2019–2026 年的历史记录）。

因此：

- 本仓库**不包含**任何原版 VB6 代码或二进制文件（版权归原作者，已在 `.gitignore` 中排除）
- 本仓库**不包含**真实名单与抽签记录（含同学姓名，同样已排除）；请用 `num.example.txt` 作为模板
- 原版的界面配色、滚动动画、防重复逻辑、跨平台适配均为本次重写新增
